## Wire the receiver

Connect VCC to 5V, GND to GND and DATA to pin 2.

![The wiring](/wp-content/uploads/2014/06/sample.jpg)

## Install the library

Install the RCSwitch library from the Library Manager.

## Read the codes

Upload this sketch and open the serial monitor at 9600 baud:

```cpp
#include <RCSwitch.h>

RCSwitch receiver = RCSwitch();

void setup() {
  Serial.begin(9600);
  receiver.enableReceive(0);
}

void loop() {
  if (receiver.available()) {
    Serial.println(receiver.getReceivedValue());
    receiver.resetAvailable();
  }
}
```

## Troubleshooting

No codes at all usually means DATA is on the wrong pin.
